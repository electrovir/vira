    Class PopoverManager

    Opens and closes a single popover element that is anchored to another element: it opens the popover in response to the anchor's interactions (see PopoverTrigger) and closes it on Escape, an outside mousedown, or the page going inactive. Style the popover with createAnchoredPopoverStyles.
